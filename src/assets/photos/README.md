# Photos

No photography exists yet, so every photo slot on the site shows a labeled placeholder naming the shot it needs.

To fill a slot, save the photo here under the slot's name and rebuild. The site picks it up on its own.

| File | Where it shows | Shape |
|---|---|---|
| `dining-room.webp` | Home · The idea | 4:5 portrait |
| `private-table.webp` | Home · Private dining | 3:2 |
| `private-room.webp` | Private Dining | 4:3 |
| `room-from-bar.webp` | Our Story | 16:9 |
| `ig-1.webp` … `ig-6.webp` | Home · From the room | square |

- WebP, under 300 KB each (`.jpg`, `.png` and `.avif` also work).
- Update the alt text for each photo in `content/photos.js` so it describes the real image.
