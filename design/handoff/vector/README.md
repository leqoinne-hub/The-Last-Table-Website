# The Last Table — Vector Logo Package (v1)

All artwork is outlined (no live fonts). Faces: Limelight (LAST TABLE), Bodoni Moda Italic ("the"), Jost (descriptor).

## Palette
Ink #14120E · Forest #0F2A1E · Linen #E3D6BC · Brass #A88B55 · Deep Cognac #7A3E1C (bulb filament only)
Pantone: Black 6 C · 5605 C · 7527 C · 871 C · 7594 C

## Files
primary/     — full lockup: the LAST TABLE / rule + bulb / SUPPER CLUB · CHICAGO. Use on ink or forest. Transparent versions for placement.
one-color/   — single-ink versions (linen, ink, black, white). Bulb filament solid. For etch, foil, emboss, stamps, receipts.
horizontal/  — the LAST TABLE | SUPPER CLUB / CHICAGO. Awning face, email header, site nav.
stacked/     — the / LAST / TABLE / rule + bulb / descriptor. Menus, door glass, hostess sign. Arch versions for menu covers.
monogram/    — tLT (with "t", 40px and up) and LT (solid, below 40px). Blade sign face at 1024.
device/      — the bulb alone.

## Rules
- Linen is the light color. Never white except one-color/white for third-party print.
- Brass is rules and hardware only. Deep cognac is the filament only.
- Bulb appears at 36px and up. Below that use the wordmark without the device or the LT monogram.
- Minimum clear space: the height of the L in LAST.
- Do not re-typeset. Do not stretch. Do not add glow.
